# Pracownia kompromisów — Bardach, krok 6

[Gra](https://rszarf-1.github.io/zlecenie-dla-doradcy-bardach/krok-6/) · [Formularz wyników i opinii](https://docs.google.com/forms/d/e/1FAIpQLSfSmRIfZi-qDYEiDFyM3Vhw87ktISLYcSsgFIxcEE9lsIwJQA/viewform) · [Spis lektur i gier](https://rszarf-1.github.io/zlecenie-dla-doradcy-bardach/materialy/)

Wydanie online 1.0.1, 16 listopada 2026. Format zapisów pozostaje 1.0.0, kod B6.1. Zachowano zadania, programy, klientów, reguły i dane z wcześniejszego wydania. Wszystkie liczby ćwiczenia są fikcyjne.

Wybierz swój program i klienta, wykonaj pięć misji. Zachowaj JSON jako kopię. W „Zapis / odczyt” rozwiń „Przenieś zapis kodem B6.1” i wybierz „Kopiuj kod”. W formularzu podaj kod, zespół i etap pracy, następnie wybierz „Prześlij”. Nie musisz przepisywać analizy. Możesz też zgłosić pracę nieukończoną.

Każda osoba przesyła własne zgłoszenie z konta UW. Zespół może użyć wspólnego kodu. Czas i opinia są dobrowolne i indywidualne; formularz zbiera zweryfikowany e-mail, więc opinie nie są anonimowe. Wypełnij formularz po rozgrywce. Przy korekcie użyj tego samego oznaczenia zespołu. Sam zapis w przeglądarce nie wysyła pracy, a przyjęcie formularza nie ocenia jakości notatek. Kod zawiera notatki i nie jest szyfrowany; nie udostępniaj go publicznie.

Po przejściu z pliku lokalnego na stronę WWW wczytaj swój JSON. Kopia w przeglądarce zależy od adresu i urządzenia. [Przekład kroków 5–6](https://drive.google.com/file/d/1OUc_5HLoF95iMhLO8aBTEAaAqBBxTxay/view) — korzystaj z części dotyczącej kroku 6.

Orientacyjny czas gry: 40–50 minut, do weryfikacji w grupie. Nie obejmuje lektury, formularza ani omówienia. Wynik zadań kontrolnych nie zastępuje oceny rozumowania przez prowadzącego.
