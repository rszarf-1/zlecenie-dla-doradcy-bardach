Wydanie online 2.2.1, 16 listopada 2026. Format zapisu 2.2.0 i kod B78.2 pozostają zgodne z wersją 2.2.

## Przygotowanie

Przed zajęciami przeczytaj przekład kroków 7–8 z materiałów prowadzącego, przygotuj własne K3, wykonaj misje 1–2 oraz kontrolę gotowości. Gra umożliwia też jawnie fikcyjny trening; nie zastępuje on własnych danych do K4. Pobierz JSON z wynikiem kontroli i zachowaj go. Możesz przesłać kod przez formularz jako zapis przed zajęciami. Jeśli potrzebujesz pomocy, nazwij problem i zgłoś go prowadzącemu odpowiednio wcześniej.

Plan 80 minut jest warunkowy: 0–6 wznowienie, 6–10 przykład, 10–28 M3, 28–41 M4, 41–49 M5, 49–64 omówienie, 64–75 fragment K4, 75–78 zapis, 78–80 rezerwa. Przy większych brakach potrzebna jest dodatkowa praca przed zajęciami lub dwa spotkania. Formularz wypełnij po rozgrywce; nie zabieraj czasu omówieniu ani K4.

## Oddawanie zapisu

1. Wybierz „Zapis i wznowienie”, potem „Kod do kopiowania” i „Kopiuj kod”.
2. Otwórz formularz, użyj konta UW, wklej kod i podaj oznaczenie zespołu oraz etap zgłoszenia.
3. Dobrowolnie dodaj czas pracy i własną opinię. Każda osoba wysyła własne zgłoszenie; wspólny kod pary jest dopuszczalny.
4. Wybierz „Prześlij” i zaczekaj na potwierdzenie. Sam zapis lub skopiowanie kodu nie wysyła pracy. Przy poprawce wyślij nowy kod z tym samym oznaczeniem zespołu.

Formularz zbiera zweryfikowany e-mail; opinie nie są anonimowe. Wynik pytań i przyjęcie formularza nie potwierdzają jakości rekomendacji ani gotowości. Nie wpisuj danych osobowych innych osób. Kod zawiera własne notatki i dossier; nie publikuj go.

## Wznowienie

Przejście z lokalnego pliku na stronę WWW wymaga przeniesienia zapisu JSON przez „Zapis i wznowienie”. Przeglądarka zapisuje postęp dla danego adresu i urządzenia. Nie zastępuje to kopii JSON.
